## 1. 성능

| 과제 | 현재 | 제안 | 효과 |
| --- | --- | --- | --- |
| 드라이브 모드 코드 더 나누기 | `/drive` 진입 시 155KB(gzip 74KB)를 한 번에 받음 | 게임·DJ·라디오를 각각 지연 로딩 (`DriveRoutes` 안에서 `lazy`) | 드라이브 첫 진입 속도 개선 |
| 라이브러리 청크 분리 | React·Router 가 공통 청크에 섞여 있음 | `react`, `react-router` 를 별도 청크로 (배포가 바뀌어도 캐시 유지) | 재방문 로딩 개선 |
| 실기기 측정 | 빌드 결과물 크기만 측정 | 배포 사이트 Lighthouse(모바일) 측정 → 목표치 설정 | 실제 체감 속도 확인 |
| 지연 로딩 중 표시 | 화면 코드를 받는 동안 빈 배경 (`LazyBoundary`) | 스켈레톤 또는 짧은 로딩 표시 | 첫 진입 시 빈 화면 체감 감소 |
| 위치 확인 중 표시 | '내 위치' 권한 응답 전 경로 미리보기가 빈 화면 | "현재 위치 확인 중…" 표시 | 혼란 방지 |

참고 수치 (최적화 전 → 후): 첫 화면 JS 583KB → 388KB, CSS 121KB → 34KB, 래스터 이미지 3.1MB → 0.94MB.

## 2. 디자인·에셋

- **차량 방향 이미지 (8방향)**: AI(GPT 이미지)로 생성해 적용 완료 (`src/features/drive/assets/car/`, 원본은 Figma '붕붕어스 차량 방향 에셋 (AI 생성)'). 디자이너 일러스트로 바꿀 때는 같은 캔버스·바닥 정렬로 8장을 만들어 파일만 교체하면 된다.
- **에셋 export 규칙**: Figma 에서 이미지를 **노드 렌더(export)** 로 받으면 캔버스 회색 배경(#F5F5F5)이 박힌다. 반드시 **원본 이미지(raw)** 를 받고 노드 크롭을 적용할 것. (드라이브 일러스트 22개를 이 방식으로 교체함)
- **앱 아이콘**: Figma 에 없어 앱 톤(코랄 그라데이션 + 차 아이콘)으로 임시 제작 (`public/icons`). 정식 아이콘 나오면 교체.
- **기록 지도 공유 아이콘**: 정사각형 이미지를 CSS 로 원형 처리 중. 홈과 같은 투명 원형 이미지로 통일 가능.
- **좁은 화면(360px)**: 홈 드라이브 배너의 '추천 테마' 값이 말줄임(…) 처리됨.
- **추천 코스 배너**: 홈에서 제거함. 다시 쓰려면 커밋 `567b5ca` 이전 코드 참고.
